Put your own photos here, one sub-folder per place:

  airbnb_a/   airbnb_b/   airbnb_c/   dusun_bonda/

Then add a line to the "photos" list of that place in data/properties.js:

  { "src": "assets/user-photos/airbnb_b/living-room.jpg", "caption": "Living room (our own photo)" }

The first photo in the list is the cover photo. Refresh the browser (F5) after saving.
